# 데이터 처리 안내

배포된 Loki 로컬 도구는 선택한 작업공간의 자막·같은 방송 영상과 근거를 읽고,
준비된 입력, 읽기 기록, 추출 이미지, 메모, 작성 응답과 보고서를 같은 작업공간에 저장합니다.
기본 멀티모달 설치의 모델 파일과 검증용 캐시는 `.models/`에, 작업별 임베딩·검색
캐시는 해당 작업공간에 보존합니다. 보고서에는 선택한 이미지 바이트가 포함될 수 있습니다.
공개 VOD 준비를 요청하면 익명 공개 API/CDN에서 지정한 영상과 사용 가능한 공개
메타데이터·채팅을 수집하고 로컬 전사·화자 전환 근거를 같은 작업공간에 보존합니다.
요청한 서비스에는 공개 URL과 다운로드 요청이 전달되며 원래 서비스의 처리 정책이
적용됩니다. 인증이 필요한 자료에는 로그인하거나 인증 상태를 가져오지 않습니다.
이 자료들은 자동으로 삭제되거나 공개되지 않습니다. 보존·백업·삭제는 작업공간
소유자가 결정합니다. 진행 중 job의 입력을 바꾸면 원자료 정합성 검사가 실패할 수 있습니다.

설치 도구는 공개 패키지 저장소와 모델 배포처에서 의존성·가중치를 내려받습니다.
기존 인증 파일을 찾거나 호스트의 모델 캐시를 자동 탐색하지 않습니다. 기존 모델을
재사용하려면 사용자가 `--model-source`로 지정한 EmbeddingGemma 2 폴더의 고정 파일만
확인합니다. Whisper·Silero·F2 자산도 작업공간의 전용 환경·`.models/`에서 관리합니다.
장치 선택에는 로컬 GPU 이름·드라이버·사용 가능 여부를 조회하며 선택 장치와
실행 검증 결과를 설치 기록에 남깁니다. 이 조회는 원자료의 외부 전송이 아닙니다.

Loki 작성 런타임의 네트워크 정책은 `deny`이고, STT와 임베딩 추론도 로컬에서 수행합니다.
설치와 명시적으로 요청한 공개 VOD 준비의 온라인 연결은 이 작성 단계와 분리됩니다.
별도 모델/API 전송이나 원격 로그 수집 기능은 제공하지 않습니다. 다만 **현재 Codex에
읽어 주는 원문·이미지는 Codex 대화의 입력**이 됩니다. 이 플러그인이 Codex의 서비스
처리나 보존 정책을 변경하지 않습니다.
공유 권한이 있는 자료만 제공하고 사용하는 Codex 계정·조직의 설정을 확인하세요.

인증 파일·토큰·쿠키·브라우저 프로필·개인 설정을 원자료 폴더에 넣지 마세요.
원문 영상·채팅·닉네임·메모·이미지·벡터 캐시·보고서에는 개인정보나 타인 저작물에
해당하는 정보가 포함될 수 있습니다.
개인 작업공간을 Git 저장소나 공개 ZIP에 포함하지 말고, 공개할 보고서는 내용과
권리를 별도로 확인하세요. 자동 마스킹이나 법적 공개 적합성 판정을 보장하지 않습니다.

기존 관리자 UI의 저장·복원도 작업공간 안에서 실행하며 외부 게시·카페 연결은
비활성화됩니다. 로컬 HTML/Markdown을 다른 곳으로 공유하는 행동은 별도입니다.

플러그인 삭제는 작업공간 삭제와 별개입니다. 재설치·업데이트 전에 원자료와
보고서·읽기 기록을 함께 백업하세요. 개인정보·보안 문제를 보고할 때 실제
자료나 비밀 값을 공개 이슈에 첨부하지 마세요. [SECURITY.md](SECURITY.md)를 참고하세요.
