# 데이터 처리 안내

Loki는 사용자가 선택한 작업공간에서 원자료를 읽고 결과를 보존합니다.
**로컬 실행과 현재 Codex 대화에 자료를 전달하는 것은 구분해야 합니다.**

## 작업공간에 저장하는 자료

| 자료 | 저장·사용 범위 |
|---|---|
| 원자료 | 자막, 같은 방송 영상, 확인된 방송 정보와 근거 |
| 작업 기록 | 준비된 입력, 원문 읽기 기록, 추출 이미지, 메모, 작성 응답과 보고서 |
| 모델·캐시 | 기본 멀티모달 설치의 모델 파일·검증용 캐시는 `.models/`, 작업별 임베딩·검색 캐시는 해당 작업공간에 보존 |
| 선택 이미지 | 보고서에 선택한 이미지 바이트가 포함될 수 있음 |

공개 VOD 준비를 요청하면 익명 공개 API/CDN에서 지정한 영상과 사용 가능한 공개
메타데이터·채팅을 수집합니다. 로컬 전사와 화자 전환 근거도 같은 작업공간에 보존합니다.
인증이 필요한 자료에 로그인하거나 인증 상태를 가져오지는 않습니다.

자료는 자동으로 삭제되거나 공개되지 않습니다. 보존·백업·삭제는 작업공간 소유자가
결정합니다. 진행 중 job의 입력을 바꾸면 원자료 정합성 검사가 실패할 수 있습니다.

## 외부 연결과 대화 입력

| 단계 | 외부 연결·처리 |
|---|---|
| 설치 | 공개 패키지 저장소와 모델 배포처에서 의존성·가중치 다운로드 |
| 요청한 공개 VOD 준비 | 익명 공개 서비스에 공개 URL과 다운로드 요청 전달. 원래 서비스의 처리 정책 적용 |
| 로컬 STT·임베딩·작성 도구 | 작성 런타임의 네트워크 정책은 `deny`. 별도 모델/API 전송이나 원격 로그 수집 기능을 제공하지 않음 |
| 현재 Codex의 읽기·작성 | **읽어 주는 원문·이미지는 Codex 대화의 입력**. 사용하는 Codex 계정·조직의 처리·보존 정책 적용 |

설치와 공개 VOD 준비의 온라인 연결은 로컬 작성 단계와 분리됩니다. 이 플러그인은
Codex 서비스의 처리·보존 정책을 변경하지 않습니다. 공유 권한이 있는 자료만 제공하고
사용하는 계정·조직의 설정을 확인하세요.

## 모델과 장치 정보

설치기는 기존 인증 파일이나 호스트 모델 캐시를 자동으로 탐색하지 않습니다.
기존 모델을 재사용하려면 사용자가 `--model-source`로 지정한 EmbeddingGemma 2
폴더에서 고정 파일만 확인합니다. Whisper·Silero·F2 자산도 작업공간의 전용 환경과
`.models/`에서 관리합니다.

장치 선택은 로컬 GPU 이름·드라이버·사용 가능 여부를 조회하고, 선택 장치와 실제
실행 검증 결과를 설치 기록에 남깁니다. 이 조회는 원자료의 외부 전송이 아닙니다.

## 보존·공유·삭제

- 인증 파일·토큰·쿠키·브라우저 프로필·개인 설정을 원자료 폴더에 넣지 마세요.
- 영상·채팅·닉네임·메모·이미지·벡터 캐시·보고서에는 개인정보나 타인의 저작물이 포함될 수 있습니다.
- 개인 작업공간을 Git 저장소나 공개 ZIP에 포함하지 마세요. 보고서를 공개할 때는 내용과 권리를 별도로 확인하세요.
- 자동 마스킹이나 법적 공개 적합성 판정을 보장하지 않습니다.

관리자 UI의 저장·복원은 작업공간 안에서 실행합니다. 외부 게시·카페 연결은 비활성화돼
있으며, 로컬 HTML/Markdown을 다른 곳으로 공유하는 행동은 별도입니다.

플러그인 삭제와 작업공간 삭제는 별개입니다. 재설치·업데이트 전에 원자료·보고서·
읽기 기록을 함께 백업하세요. 개인정보·보안 문제를 보고할 때 실제 자료나 비밀값을
공개 이슈에 첨부하지 마세요. [보안 문제 보고](SECURITY.md)를 참고하세요.
