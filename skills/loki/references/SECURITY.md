# 보안 안내와 문제 보고

보안 문제는 실제 원자료나 비밀값을 공개하지 않고 재현할 수 있게 알려주세요.
비공개 보안 보고 기능이 안내돼 있으면 그 경로를 사용하세요. 연락이 필요하면 공식
문의 주소 [ttaem00@naver.com](mailto:ttaem00@naver.com)으로 먼저 알려주세요.

## 보고에 포함할 내용

- 사용한 버전과 재현 명령
- 예상 동작과 실제 동작
- 비밀값을 제거한 오류 메시지
- 가능하면 합성 자막·가짜 식별자·최소 코드로 만든 재현 자료

토큰·쿠키·인증 파일·개인 방송 자료·전체 작업공간·개인 경로가 담긴 로그를 공개
이슈에 첨부하지 마세요.

## 로컬 실행과 권한의 경계

Loki의 `network=deny`는 로컬 도구의 실행 정책이며 OS sandbox가 아닙니다.
신뢰할 수 있는 배포본을 사용하고 설치 호스트의 파일·네트워크 권한을 따르세요.
현재 ChatGPT 또는 Codex 대화의 서비스 처리와 권한에는 해당 계정·조직 정책이 적용됩니다. ChatGPT 모드의 로컬 세션 UUID는 작업 소유 범위와 재개를 위한 출처 정보이며 플랫폼 계정 인증을 증명하지 않습니다.

공개 VOD 준비는 사용자가 지정한 단일 공개 치지직 URL과 허용된 공개 서비스 연결로
제한합니다. 로그인·쿠키·프로필 복사나 제한된 VOD의 인증 우회는 지원하지 않습니다.
작성 중에는 이 온라인 준비 경로를 호출하지 않습니다.

보고서 작성 중 런타임이 임의 shell이나 다른 모델 작성자를 실행하면 보안 문제로
다뤄 주세요. 설정·도구 실행 기록·모델 manifest를 수동으로 바꿔 검사를 우회하지 마세요.

## 로컬 편집 서버

편집 서버는 기본 `127.0.0.1`에만 연결합니다. Docker 편집 서비스도 호스트의
`127.0.0.1:8787`에만 포트를 연결합니다. 인터넷이나 공유 네트워크에 직접 노출하지 마세요.

수정 요청은 같은 출처의 Host·Origin 및 JSON 요청 검사를 따릅니다. 미리보기 생성과
revision 일치 검사를 거치며, 화면은 원문 SRT와 선택 이미지의 근거를 읽기 전용으로
다룹니다. 기존 관리자 UI의 API 호환 경로와 직접 preview/save API의 요청 형식은
서로 다르므로 임의로 섞지 마세요. 저장 충돌을 피하려고 revision이나 preview ID를
임의로 바꾸면 안 됩니다.

## 도구·모델·GPU

| 구성요소 | 실행·검증 조건 |
|---|---|
| 미디어 도구 | `.loki-tools.json`의 실행 파일·SHA-256, 고정 FFmpeg protocol/format과 로컬 입력·출력 경로로 제한 |
| 작성 도구의 Node·멀티모달 worker | Node는 지정된 댓글 parser만 실행. 멀티모달 Python worker는 고정 모델과 소유 spec으로 호출 |
| EmbeddingGemma 2 | 고정 revision의 13개 파일을 해시 검사. 로드 시 `local_files_only=True`, `trust_remote_code=False`, `token=False` 사용 |
| 로컬 STT | workspace 영상·새 SRT 출력과 해시를 확인한 Whisper·Silero·F2 자산만 사용. Whisper는 고정 revision의 모델·processor 파일을 검증하고 local-files-only 방식으로 로드. Silero는 설치 패키지의 JIT, F2는 고정 공개 ONNX 자산 사용 |
| GPU | 호스트 드라이버와 Docker GPU 지원 필요. 컨테이너가 호스트 kernel 드라이버를 설치·교체하지 않으며 privileged 권한이나 Docker socket을 요구하지 않음 |

설치 단계는 공개 의존성과 모델을 내려받습니다. 모델·패키지 업데이트는 새 배포본의
설치 경로를 사용하고 기존 작업공간과 결과를 보존하세요. 장치 감지와 실제 GPU 실행
검증은 구분합니다.

제3자 고지를 함께 유지하세요. 사용자 설정·인증·방송 원자료·개인 작업 결과는
배포본에 포함하지 마세요.
