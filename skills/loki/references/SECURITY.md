# 보안 문제 보고

보안 문제를 보고할 때는 사용한 버전, 재현 명령, 예상·실제 동작과 비밀 값을 제거한 오류를 알려주세요. 합성 자막·가짜 식별자와 최소 코드로 재현할 수 있으면 실제 원자료 없이 조사할 수 있습니다.

토큰·쿠키·인증 파일·개인 방송 자료·전체 작업공간·개인 경로가 담긴 로그를 공개 이슈에 첨부하지 마세요. 저장소에 비공개 보안 보고 기능이나 별도 연락 경로가 안내되어 있으면 해당 경로를 사용하세요.

Loki의 `network=deny`는 로컬 도구의 실행 정책이며 OS sandbox가 아닙니다. 신뢰할 수 있는 배포본을 사용하고 설치 호스트의 파일·네트워크 권한을 따르세요. 현재 Codex의 서비스 처리와 권한은 해당 계정·조직 정책의 적용을 받습니다.

로컬 편집 서버는 기본 `127.0.0.1`에만 연결합니다. Docker 편집 서비스도 호스트의 `127.0.0.1:8787`에만 포트를 연결합니다. 인터넷이나 공유 네트워크에 직접 노출하지 마세요. 수정 요청은 같은 출처의 Host·Origin 및 JSON 요청 검사를 따르고, 미리보기 생성과
revision 일치 검사를 거칩니다. 기존 관리자 UI의 API 호환 경로와 직접 preview/save
API의 요청 형식은 서로 다르므로 임의로 섞지 마세요. 저장 충돌을 우회하려고 revision이나 preview ID를 임의로 바꾸지 마세요. 화면은 원문 SRT와 선택 이미지의 근거를 읽기 전용으로 다룹니다.

미디어 실행은 `.loki-tools.json`의 실행 파일·SHA-256, 고정된 FFmpeg protocol/format과 로컬 입력·출력 경로로 제한합니다. Node는 지정된 댓글 parser만 실행하며 멀티모달 Python worker는 고정 모델과 소유 spec으로 호출합니다. 설정·도구 receipt·모델 manifest를 수동으로 바꿔 검사를 우회하지 마세요. 보고서 작성 중 런타임이 임의 shell이나 다른 모델 작성자를 실행하는 경우 보안 문제로 다뤄주세요.

공개 VOD 준비는 사용자가 지정한 단일 공개 치지직 URL과 허용된 공개 서비스 연결로
제한합니다. 로그인·쿠키·프로필 복사나 제한된 VOD의 인증 우회는 지원하지 않습니다.
작성 중에는 이 온라인 준비 경로를 호출하지 않습니다. 로컬 STT는 workspace 영상과
새 SRT 출력, 해시를 확인한 Whisper·Silero·F2 자산만 사용합니다.

설치 단계는 공개 의존성과 모델을 내려받습니다. EmbeddingGemma 2는 고정 revision의 13개 파일을 해시 검사하며 로드 시 `local_files_only=True`, `trust_remote_code=False`, `token=False`를 사용합니다. Whisper도 고정 revision의 모델·processor 파일을 검증하고 local-files-only 방식으로
로드하며, Silero는 설치한 패키지의 JIT, F2는 고정 공개 ONNX 자산을 사용합니다.
모델·패키지 업데이트는 새 배포본의 설치 경로로 수행하고 기존 작업공간과 결과를 보존하세요.

GPU 실행에는 호스트 드라이버와 Docker GPU 지원이 필요합니다. 컨테이너의 패키지가 호스트 kernel 드라이버를 설치하거나 교체하지 않으며 privileged 권한이나 Docker socket도 요구하지 않습니다. 장치 감지와 실제 GPU 실행 검증은 구분합니다.

재배포할 때는 `release-manifest.json`의 파일·해시가 실제 내용과 일치하는지 확인하고 라이선스와 제3자 고지를 함께 유지하세요. 사용자 설정·인증·방송 원자료·개인 작업 결과는 배포본에 포함하지 마세요.
