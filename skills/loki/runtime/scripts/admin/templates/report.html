          장면 편집 화면 열기
        
    
        
    
        
    
          
    
          
          
        
    
      
    
      
    
        
    
          타임라인 카드를 누르면 여기서 그 장면이 재생됩니다.
          새 탭에서 열기 ↗
        
    
        
      
    
      
    
      
    
    
    
    
    
    
      
    편집 조종석
    
      
    장면을 찾고, 근거를 확인하고, 요약 후보를 미리 본 뒤 본문에 넣는 관리자 전용 작업창입니다.
    
      
    
      
    
        
    
          
    1. 장면 찾기
    
          
    채팅 급증, 웃음/놀람, 긴 자막, 시청자 클립, 오디오 피크, 기존 요약 구간을 시간축으로 봅니다.
    
          
    시그널 타임라인 데이터가 없습니다.
    
        
    
        
    
          
    번들 정렬 근거
    
          
    번들에 포함된 VOD의 유튜브 편집본 정렬 후보입니다. 검토 완료만 근거로 보고, 자동 후보와 실패 기록은 확인 대상으로 표시합니다.
    
          
    번들 정렬 근거가 없습니다.
    
        
    
        
    
          
    번들 구성 바꾸기
    
          
    VOD 번호를 줄마다 하나씩 정리해 미리보기로 변경점을 확인합니다. 저장 전에는 번들 파일이 바뀌지 않습니다.
    
          
          
    
            
            
            
          
    
          
    VOD 번호를 조정한 뒤 미리보기를 누르세요.
    
        
    
        
    
          
    2. 선택한 시각의 근거
    
          
    선택한 장면 주변 자막, 채팅, 기존 요약 맥락을 확인하고 필요하면 시각을 직접 고칩니다.
    
          
    
            
            
            
          
    
          
    시간축을 클릭하거나 타임코드를 입력하세요.
    
        
    
        
    
          
    3. 요약에 추가하기
    
          
    선택한 시각과 위 근거를 바탕으로 `### 📍 타임라인 상세 요약`에 넣을 후보 1개만 만듭니다.
    
          
          
    
            
            
          
    
          
    후보를 만들면 여기에 미리보기가 표시됩니다.
    
        
    
        
    
          
    4. 내가 표시한 장면
    
          
    장면 찾기에서 중요/제외/추가 검토로 남긴 판단이 모입니다. 요약 본문을 고칠 때 다시 볼 개인 체크리스트입니다.
    
          
    
          
    
        
    
        
    
          
    댓글 보조 장면 검증
    
          
    같은 관리자 편집 기록에서 댓글 보조 장면을 넣었을 때와 뺐을 때의 수정 부담을 비교합니다. 댓글은 장면의 정답이 아니라 보조 신호로만 봅니다.
    
          
    검증 결과를 불러오는 중입니다.
    
        
    
        
    
          
    5. 메모를 작업 초안으로 보기
    
          
    제목, 장면 제외, 단어 후보, 근거 확인처럼 큰 메모를 저장 없이 초안 카드로만 확인합니다.
    
          
          
    
            
            
          
    
          
    메모를 입력하면 저장 없이 작업 초안만 표시됩니다.
    
        
    
        
    
          
    6. 승인함
    
          
    요청의 위험·효과·출처를 읽고 승인하거나 거절합니다. 승인 기록과 단어 사전 적용 결과는 따로 표시하며, 여기서 처리해도 편집 중인 본문은 유지됩니다.
    
          
    승인 요청을 불러오는 중입니다.
    
        
    
        
    
          
            편집 프로그램용 컷 목록
            필요할 때만
          
          
    영상 편집 프로그램이나 외부 도구로 컷 목록을 복사할 때만 쓰는 보조 자료입니다.
    
        
    
        
    
          
            저장 전 자동 경고
            문제 있을 때만
          
          
    챕터 시간, 근거 누락, 구간 경계처럼 저장 전에 한 번 볼 경고가 있을 때 표시됩니다.
    
        
    
        
    
          
            반복 이름 후보
            단어 사전 보조
          
          
    여러 context.md에 반복 등장한 이름/용어입니다. 표기·고유명사·배경 힌트일 뿐, 특정 장면이 실제로 있었다는 근거는 아닙니다.
    
          
    반복 후보를 불러오는 중입니다.
    
        
    
      
    
    
    
  
    
  
    
    
    
      
    
        
    
          
    되돌리기 기록
    
          
    저장/공개 반영 시점의 본문과 화면을 봅니다. 이전 버전을 불러와도 저장 전까지 파일과 공개 사이트는 바뀌지 않습니다.
    
        
    
        
      
    
      복구 안전망
      
    
        
    AI 원본AI가 처음 만든 기준본입니다. 공개 대상 아님.
    
        
    사람 수정관리자가 저장하거나 불러온 편집본입니다. 공개 대상 아님.
    
        
    공개 미리보기승인 기록이 있는 현재 공개본 화면입니다.
    
      
    
      
    
        
    기록을 불러오는 중입니다.
